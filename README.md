# Winsome's Meal & Life Plan

A mobile-first personal wellness planner with a purple/lilac theme.

## Prototype features
- Nigerian meal inspiration based on foods Winsome enjoys
- Food diary with optional meal photo preview
- Daily water tracker
- Sweet-craving check-in
- Grocery checklist and user-entered market estimates in naira
- Activity log, including Tuesday and Saturday swimming lessons
- Weight and body-measurement check-ins
- Browser-local persistence with localStorage

## Run locally
Open `index.html` in a modern browser or serve this folder with a static web server.

## Important limitations
This is a front-end prototype. Entries are stored only in the current browser/device and are not synced or backed up. It does not yet include accounts, a secure database, cloud photo storage, automated reminders, or live Nigerian market prices. Do not use it for sensitive information on a shared device.

Before public or multi-device use, add secure authentication, a backend, database access controls, private image storage, validation, backups, and privacy/security testing. Wellness content is general information, not medical advice or PCOS treatment.
